# Dossier de conversion

Déposez ici un ebook **PDF** ou **Word (.docx)** : sa conversion en livre audio démarre automatiquement.

1. Dépôt : bouton « Add file » puis « Upload files » sur cette branche.
2. Suivi : onglet **Actions**, « Ebook vers livre audio, conversion ». Le résumé affiche un lien quand le livre est prêt.
3. Résultat : onglet **Releases**, une Release par livre avec le **.m4b** et le ZIP des MP3.

Les réglages (voix, vitesse, ton…) sont dans `reglages.txt`.
Pour reconvertir un livre avec d'autres réglages, déposez-le de nouveau sous un autre nom.
