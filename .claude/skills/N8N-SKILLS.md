# n8n-skills (tiers)

Les dossiers `n8n-*` et `using-n8n-mcp-skills` de ce répertoire proviennent de
https://github.com/czlonkowski/n8n-skills (plugin `n8n-mcp-skills` v1.35.0,
commit `19cd793f4789e3ef9c657ccf26e097f641a77df0`), copiés tels quels
(installation manuelle, méthode 3 du README amont).

Ils complètent le serveur MCP `n8n-mcp` déjà déclaré dans `.mcp.json`.
Les hooks optionnels du plugin (rappels de chargement des skills) ne sont pas
installés ; pour les avoir, installer plutôt le plugin :
`/plugin install czlonkowski/n8n-skills`.

Mise à jour : recopier `skills/*` depuis une version plus récente du dépôt.
