# Vidéo « Claude Code × Remotion, la méthode en 5 prompts »

Vidéo verticale 1080x1920, 30 i/s, 2 minutes, avec musique originale générée par script.

- Aperçu : `npm run studio`
- Régénérer la musique : `npm run music` (crée `public/musique.mp3`)
- Exporter : `npm run render` (sortie dans `sorties/`)

Plan de montage (dans `src/Video.tsx`) :

| Temps | Scène |
|---|---|
| 0:00 à 0:08 | Accroche |
| 0:08 à 0:20 | Le principe : prompt, code, vidéo |
| 0:20 à 1:50 | Étapes 1 à 5 (18 s chacune) : titre, prompt tapé en direct, démo animée, 2 cartes conseils |
| 1:50 à 2:00 | Récap et appel à l'action |

Pour la vidéo suivante : changer les textes du tableau `steps` puis relancer l'export.
